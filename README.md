A lighthouse on a dark cliff whose lamp beam is a spiral galaxy: a glowing two-armed spiral of stars sweeps out of the lamp across a starry night sky, with a shooting star, a milky-way band and warm lamplight against deep indigo. Drawn by a deterministic Python program (Pillow + numpy) and written out as a 1024×1024 PNG.

## Run it

```sh
python3 main.py
```

`main.py` is standard library only and writes the artwork to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`). The image itself lives in the repo as base64 in `art.b64`. To regenerate the artwork from scratch:

```sh
python3 draw.py
```
